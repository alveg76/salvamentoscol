# 🚀 INICIAR AQUÍ - Salvamentos y Usados

## ⚡ 3 PASOS PARA VER TU SITIO

### PASO 1: Abrir Terminal PowerShell
```powershell
# Copia y pega esto en PowerShell
cd c:\salva
```

### PASO 2: Iniciar Servidor
```powershell
npm run dev
```

### PASO 3: Abrir en Navegador
```
http://localhost:3000
```

---

## ✅ Debería ver:

1. **Header Amarillo y Negro** - Con navegación y botón WhatsApp
2. **Banner Principal** - Con "Salvamentos y Usados" en grande
3. **Sección Nosotros** - Con 8 años de experiencia destacados
4. **Catálogo** - Con link a Instagram
5. **Contacto** - Con todos los teléfonos y WhatsApp
6. **Footer** - Con información y redes sociales

---

## 📱 Prueba en Móvil

Desde tu móvil en la misma red WiFi:
1. Abre navegador
2. Ve a: `http://[tu-ip-local]:3000`
   - Ejemplo: `http://192.168.1.100:3000`
